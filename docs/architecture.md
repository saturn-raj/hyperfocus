# Architecture

| Boundary                         | Responsibility and rules                                                                                                                                                                                                                                                                                                            |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/domain/model.ts`            | Versioned Zod schema, entities, calendar-date helpers. All input and persistence passes through this schema. No React, DOM state, or storage imports.                                                                                                                                                                               |
| `src/domain/planning.ts`         | Pure overlap checks, time accounting, timer math, goal coverage, and draft scheduling. Depends only on domain types and platform primitives.                                                                                                                                                                                        |
| `src/domain/onboarding.ts`       | Pure draft creation, explicit line-to-goal conversion, step validation, capacity checks and atomic season construction.                                                                                                                                                                                                             |
| `src/ui/onboarding`              | Individual setup steps render fields; the Onboarding page owns transitions and persistence through application commands.                                                                                                                                                                                                            |
| `src/domain/seed.ts`             | Optional example workspace and clean initialization. Relative dates keep examples usable.                                                                                                                                                                                                                                           |
| `src/application/store.ts`       | Framework-independent commands and subscriptions with an injected repository. Validates and persists before publishing mutations. Failed writes leave memory unchanged and surface errors.                                                                                                                                          |
| `src/infrastructure/storage.ts`  | Browser localStorage adapter, bounded JSON parsing, downloads. Corrupt storage is preserved until explicit recovery/reset.                                                                                                                                                                                                          |
| `src/infrastructure/calendar.ts` | RFC 5545 event export, UTC timestamps, escaping and UTF-8 line folding. Snapshot only.                                                                                                                                                                                                                                              |
| `src/application/ports.ts`       | Persistence contract owned by the application; adapters implement it.                                                                                                                                                                                                                                                               |
| `src/bootstrap.ts`               | Composition root wires the repository and cross-tab events. `src/ui/useWorkspace.ts` connects React subscriptions.                                                                                                                                                                                                                  |
| `src/ui/components`              | Radix dialog with focus trapping and Escape dismissal; goal, task and time-block forms.                                                                                                                                                                                                                                             |
| `src/ui/pages`                   | Planner, Season, Focus, Compass, Settings. Pages call application commands and derive presentation from domain state. Secondary pages load lazily.                                                                                                                                                                                  |
| `src/ui/App.tsx`                 | Navigation, theme, notifications, global blocker heartbeat. Timer state continues across page navigation because it lives in the application store.                                                                                                                                                                                 |
| `extension`                      | Separate MV3 package. A fixed-origin bridge forwards validated session state. The worker serializes updates to ephemeral domain navigation rules, with an expiring heartbeat lease.                                                                                                                                                 |
| Persistence                      | One versioned document, written synchronously and atomically per localStorage operation. No server, account, external data transmission, migrations beyond schema v1, or distributed merge semantics.                                                                                                                               |
| Time                             | Local civil dates for planning. UTC epoch timestamps for sessions. Countdown derives from persisted remaining time and running timestamp, never interval counts. System clock changes can affect timers.                                                                                                                            |
| Scheduling                       | Exact editor rejects overlaps and midnight spillover. Draft visits unfinished unscheduled tasks by priority, searches 15-minute slots, 09:00–17:00 weekdays, reserves 12:00–13:00, and excludes earlier dates. No inferred task decomposition.                                                                                      |
| Goal deletion                    | Preserve tasks, blocks and historical sessions by removing their goal reference. Task deletion similarly detaches references without destroying focus history.                                                                                                                                                                      |
| Task completion                  | Explicit action updates linked block completion. Focus logging does not assume a task is complete.                                                                                                                                                                                                                                  |
| Coaching                         | Compare weekly scheduled minutes to user-selected targets. This measures plan coverage, not outcome probability, scientific efficacy, or AI judgment.                                                                                                                                                                               |
| Errors                           | Actionable form errors and notifications; corrupt-save recovery in Settings; render error boundary. Browser quota and disabled-storage errors do not silently discard writes.                                                                                                                                                       |
| Scaling                          | Implement the `Repository` port to add authenticated synchronization. Introduce version migrations and conflict policy first. Add remote coach/calendar adapters separately, with secrets held server-side.                                                                                                                         |
| Verification                     | Domain/storage tests for date and timer boundaries, conflicts, draft invariants, validation and ICS. Playwright covers create → schedule → reload → focus → pause/reload → save → reflect; backup, theme, search, reset, mobile overflow. Extension privileged behavior requires manual verification.                               |
| First-run data                   | New browsers start empty. Optional onboarding metadata defaults safely for old backups; saved drafts resume at their last step. Completion atomically adds linked goals, milestones, first actions and an optional time block, preserving existing tasks, blocks and history. The signed commitment remains on the season overview. |
