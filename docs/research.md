# Product research and implementation coverage

| Source / capability                                            | Finding and current implementation                                                                                                                                                                               |
| -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Superfocus homepage](https://www.superfocus.me/)              | Describes goals, planning, protected focus and coaching. Hyperfocus implements an independent local planning loop.                                                                                               |
| [Public product walkthrough](https://www.superfocus.me/go/lp1) | Shows seasons, ranked outcomes, time blocks, focus and review. Marketing claims do not establish the private algorithms.                                                                                         |
| [REA investigation](research/rea-superfocus.md)                | Five shipped client bundles inspected with REA and focused source reads. Evidence IDs, hashes, static observations, runtime boundaries and unanswered questions are recorded.                                    |
| Supplied plan screenshot                                       | Directly establishes separate seasonal outcomes and support areas, core/secondary priorities, and add/remove controls. The rebuilt review models those concepts independently.                                   |
| New-user flow                                                  | Narrative → relevant follow-up questions → editable proposal → editable commitment and explicit signature. Dates and questions resume across reloads. Accepted original answers stay separate from edited goals. |
| Coaching                                                       | Local guided rules are the default. A server-side OpenAI-compatible adapter can generate questions, plans and commitments when configured. Its prompts are original, not recovered from Superfocus.              |
| Seasons                                                        | Editable goals, finish lines, first actions, priorities, budgets, milestones, separate support areas and signed commitment history. Full previous-season carry/archive behavior is not implemented.              |
| Planning                                                       | Day/week calendar, task scheduling, dragging, exact editing, overlap checks and rule-based week drafts. Calendar connection is one-way ICS export only.                                                          |
| Focus                                                          | Persistent timer, pause/resume, ratings, brown noise and optional Chrome navigation blocking. Native foreground tracking and device-wide blocking are not implemented.                                           |
| Accountability                                                 | Recorded focus time, weekly goal coverage, explicit completion, reflections and energy capture. No claimed outcome-probability model.                                                                            |
| Integrations                                                   | OAuth calendar sync, Slack status, meeting-note ingestion, native clients and cross-device accounts remain unimplemented.                                                                                        |
| Independence and privacy                                       | Proprietary artifacts stay outside the repository. Personal onboarding answers are not public fixtures. The implementation has its own code, identity and provider contract.                                     |
