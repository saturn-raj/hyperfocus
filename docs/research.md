# Product research and implementation coverage

| Source / capability                                                                               | Finding and Hyperfocus response                                                                                                                                                                                                                                                                                                                                                   |
| ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Superfocus homepage](https://www.superfocus.me/), inspected 4 November 2026                      | Public positioning joins goals, a calendar, focused work and coaching. Pricing and marketing are not part of this implementation.                                                                                                                                                                                                                                                 |
| [Product walkthrough](https://www.superfocus.me/go/lp1), inspected 4 November 2026                | Shows seasons, ranked goals, milestones, calendar blocks, timer, reflections and weekly assessment. Hyperfocus independently implements this planning loop with its own interface.                                                                                                                                                                                                |
| [Web application](https://app.superfocus.me/)                                                     | JavaScript application returned no readable authenticated product content to the research fetch. The publicly delivered season-planning bundle exposes an introductory sequence, season length, brain dump, follow-up questions, draft goals, and a signed commitment. Authenticated runtime behavior and server-generated questions remain unverified. No paid account was used. |
| [Developer’s Android listing](https://play.google.com/store/apps/details?id=me.superos.companion) | Describes a mobile companion, focus blocking, calendar views and Slack status. Hyperfocus supplies a responsive web UI and optional Chrome navigation blocker, not native mobile blocking.                                                                                                                                                                                        |
| Seasonal planning                                                                                 | Editable date range, priority, purpose, weekly effort, task breakdown and milestones are implemented. Automatic goal decomposition is absent.                                                                                                                                                                                                                                     |
| Time protection                                                                                   | Manual blocks, drag scheduling, conflict detection, and a deterministic draft with review are implemented. Calendar sync is limited to one-way ICS export.                                                                                                                                                                                                                        |
| Focus                                                                                             | Countdown, pause/resume, ratings, noise, history and optional website navigation blocking are implemented. Automatic foreground-app tracking and native device blocking are absent.                                                                                                                                                                                               |
| Accountability                                                                                    | Measured focused time, weekly target coverage, explicit task/milestone completion, daily reflection and energy capture are implemented. Coverage labels do not predict whether outcomes will happen.                                                                                                                                                                              |
| Coach                                                                                             | Public claims describe conversational assistance and contextual recommendations. Hyperfocus uses transparent local scheduling and coverage rules. It does not imitate a remote AI service.                                                                                                                                                                                        |
| Integrations                                                                                      | No OAuth credentials, calendar write access, Slack status, meeting-note ingestion, cross-device identity, or remote synchronization are included. Those require separate authenticated adapters.                                                                                                                                                                                  |
| Independence                                                                                      | All implementation code, UI and example data were created for Hyperfocus. No private endpoints, source code, paid assets, testimonials or trademarks were copied.                                                                                                                                                                                                                 |
| Onboarding correction                                                                             | First-run setup now precedes the workspace. Hyperfocus independently implements the sequence with local questions and explicit user-written outcomes; it does not call or copy Superfocus’s private coach. Existing backups without setup metadata are read with an incomplete-setup default while retaining their data.                                                          |
